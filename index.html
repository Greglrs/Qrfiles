Optique

Transfert de fichier entre deux appareils sans wifi ni Bluetooth. L'émetteur découpe le fichier en paquets et les affiche en QR codes défilants ; le récepteur les capte à la caméra et reconstitue le fichier.
Paquet 0 / 0 — cycle 1
Vitesse 220 ms/paquet
0 / ? paquets — en attente…
Débit réel attendu : ~15–30 Ko/s selon la caméra et la distance à l'écran. Ceci est une base fiable (QR séquentiel + hash) ; les versions suivantes (grille couleur dense, fountain codes) visent 10–15× ce débit. Tout tourne dans le navigateur, sans backend.
